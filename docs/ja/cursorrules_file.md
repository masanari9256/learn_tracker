# .cursorrules

## プロジェクト概要

*   **タイプ：** cursorrules_file
*   **説明：** 学生、教育者、自己学習者が日々の学習活動を記録し、その進捗や強み・弱みを視覚的に把握できるウェブベースのプラットフォーム。安全なユーザー認証、マークダウンエディタによるエントリー、リアルタイムダッシュボード、CSVエクスポート、Stripeを用いたサブスクリプション管理など、多角的な機能を提供します。
*   **主要目標：** ユーザーが毎日の学習を効率的に記録し、進捗を把握しながら自己改善を促すとともに、分かりやすい分析やAIによる推奨機能で学習体験を最適化する。

## プロジェクト構造

### フレームワーク固有のルーティング

*   **ディレクトリルール：**

    *   Next.js 14（Appルーター）：高度なルーティングのために、ネストされたルートフォルダを持つ`app/`ディレクトリの使用を強制します。例えば、動的ルートは`app/[route]/page.tsx`の規則に従います。
    *   例1：「Next.js 14（Appルーター）」→ `app/[route]/page.tsx`の規則
    *   例2：「Next.js（Pagesルーター）」→ `pages/[route].tsx`パターン（ここでは適用されません）
    *   例3：「React Router 6」→ `createBrowserRouter`を使用する`src/routes/`

### コアディレクトリ

*   **バージョン管理された構造：**

    *   app/api：サーバーサイドロジック用の組み込みルートハンドラーを持つNext.js 14 APIルート
    *   app/auth：Supabase統合を使用したログインと登録を含む認証ページ専用フォルダ
    *   app/dashboard：リアルタイム分析とユーザーダッシュボード用のレイアウトとページを含む

### 主要ファイル

*   **スタックバージョン管理されたパターン：**

    *   app/dashboard/layout.tsx：Next.js 14でダッシュボードコンポーネントのルートレイアウトを確立
    *   app/entry/page.tsx：マークダウン対応の日々の学習入力ページを実装
    *   app/auth/login/page.tsx：サーバーアクションを使用してセキュアなログインフローを管理

## 技術スタックルール

*   **バージョン強制：**

    *   next@14：Appルーターが必須。`pages/`ディレクトリとレガシーなルーティング方法（`getInitialProps`など）の使用は許可されません。
    *   <typescript@4.x>：プロジェクトの一貫性のために厳密な型付けを強制
    *   <tailwindcss@3.x>：レスポンシブデザインと迅速なUI開発のためにTailwind CSSを活用

## PRD準拠

*   **譲れない要件：**

    *   「StudyTracker Proは、学生、教育者、独学者が日々の学習活動を記録し追跡するために設計されたWebベースのプラットフォームです。」これは、セキュアなユーザー認証、マークダウン対応のエントリー、進捗の可視化のためのリアルタイムダッシュボードを必要とします。

## アプリフロー統合

*   **スタック整合フロー：**

    *   例：「Next.js 14認証フロー → `app/auth/login/page.tsx`はサーバーアクションを使用してユーザー認証とセッション管理を安全に管理します。」
